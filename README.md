# Bài thực hành phối màu đơn tông - CodeGym

Website HTML/CSS/JavaScript chạy độc lập, không cần cài đặt.

## Cách chạy

Mở `index.html` bằng Chrome hoặc Edge.

## Đã làm
- Màu chính tông xanh `#00ADEE`.
- Nền phần đầu `#00BFF2`.
- ON SALE/PREVIEW `#00ADEE`.
- Nền nội dung `#8DD7F7`.
- Footer `#C6E9FA`.
- Chữ màu đen (trừ nút/chỉ báo cần độ tương phản).
- Bấm **Chuyển sang tông tím** để xem phiên bản đơn sắc thứ hai (bước 8).

## Lưu ý
Đây là website độc lập mô phỏng bài thực hành, không phải chỉnh sửa trực tiếp bộ mã gốc `Pra.zip` vì chưa tải được tệp ZIP nguồn trong phiên làm việc.

## Đưa lên GitHub
Tạo repository mới, tải 4 file lên thư mục gốc, sau đó nộp đường dẫn repository.
